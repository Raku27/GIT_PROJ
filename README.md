## 📁 Projects

### 1. 📊 [Data Hotel Analysis with PowerBI](./01-data-hotel-analysis-powerbi)
Comprehensive hotel data analysis and visualization using PowerBI. This project demonstrates data cleaning, transformation, and interactive dashboard creation for business intelligence.

**Key Features:**
- Data extraction and transformation
- Interactive PowerBI dashboards
- Business insights and analytics
- Performance metrics visualization

### 2. [Matching Optimization API](./02-matching-project)
A tested Python/FastAPI service comparing maximum-total-score assignment and stable preference matching.

- Shared scoring, candidate/job field mappings, and per-attribute explanations
- 46 algorithm/API tests, including exhaustive small-case optimality and blocking-pair checks
- [Measured latency and memory](./02-matching-project/docs/benchmarks.md) for 10–200 entities per group
- [Two-minute local demo](./02-matching-project/docs/demo.md) showing why stability and total score differ

[Setup and limitations](./02-matching-project/README.md) · [API guide](./02-matching-project/docs/api_usage_guide.md)

### 3. [Common Project Runner](./03-engineering-pipeline-agent)
A configuration-driven Python runner for real project commands, with dependency gates, deadlines and per-run logs/reports.

- Reusable JSON configurations for Matching API and runner regression checks
- Real exit-code handling, bounded logs, process-group cleanup and fresh run state
- Matching API's GitHub workflow uses the shared runner
- [One-command Docker workflow](./03-engineering-pipeline-agent/docs/docker.md) with reports saved on the host
- [Setup and current limitations](./03-engineering-pipeline-agent/README.md)

### 4. 🤖 [AI Analysis](./04-ai-analysis)
Advanced AI-powered analysis system for data insights and predictions. Showcases machine learning, deep learning, and AI model deployment.

**Key Features:**
- Machine learning models
- Data preprocessing and feature engineering
- Model evaluation and metrics
- Production-ready deployment
